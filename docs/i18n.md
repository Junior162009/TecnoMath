# TecnoMath — internacionalización (i18n)

## Arquitectura

TecnoMath usa un runtime central en `js/i18n.js` y un registro en `locales/index.json`.

- Idioma guardado: `localStorage.tecnomath_language`.
- Detección inicial: idioma guardado → idioma del navegador → español.
- Fallback: español (`es`) y, como último recurso, el texto/key existente.
- Carga: los JSON de idioma se solicitan bajo demanda y quedan en memoria/cache del navegador.
- RTL: `ar`, `he`, `fa`, `ur`, `ps`, `ku` y `sd` están marcados como RTL.
- Variables: `t('score.points', { points: 100 })`.

## Uso en HTML

```html
<button data-i18n="common.play"></button>
<input data-i18n-placeholder="common.search">
<span data-i18n-title="accessibility.languageSelector"></span>
```

Para contenido generado dinámicamente, llamar después de insertar el nodo:

```js
window.TecnoMathI18n?.translatePage();
```

## Uso en JavaScript

```js
const text = window.TecnoMathI18n?.t('score.points', { points: 100 });
await window.TecnoMathI18n?.setLanguage('en');
```

## Juegos nuevos

1. Mantener la lógica y los datos del juego independientes del idioma.
2. Añadir las cadenas visibles mediante claves `data-i18n` o `t()`.
3. Crear `games/<juego>/locales/es.json` y los demás locales cuando existan traducciones revisadas.
4. No inventar traducciones educativas.
5. Si una traducción no está disponible, permitir el fallback.

## Traducciones

El registro puede contener más de 100 idiomas aunque no todos tengan todavía un archivo traducido. Esto es intencional: registrar un idioma no significa declarar que su contenido educativo ya está traducido. Los idiomas sin locale propio usan el fallback español hasta que exista una traducción revisada.

## Validación

Ejecutar desde la raíz:

```bash
node scripts/validate-i18n.mjs
```

El validador comprueba JSON, códigos duplicados, idioma/fallback, claves faltantes, claves sobrantes y traducciones vacías. No declara PASS cuando hay errores.

## Regla de seguridad

La internacionalización no debe cambiar autenticación, Supabase, progreso, puntuaciones, rankings, votaciones, controles ni mecánicas de los juegos.
