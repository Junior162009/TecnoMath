# TecnoMath — internacionalización global

## Arquitectura

`js/i18n.js` es el runtime central y `locales/index.json` es el registro de idiomas.

- Selección inicial: idioma guardado → idioma del navegador → español.
- Persistencia: `localStorage.tecnomath_language`.
- Fallback: español; si una clave tampoco existe, se conserva un fallback seguro.
- Lazy loading y cache: no se descargan los 100 idiomas al mismo tiempo.
- RTL preparado mediante `dir="rtl"` para idiomas marcados RTL.
- Variables: `TecnoMathI18n.t('score.points', {points: 100})`.
- Selector global accesible y responsive.

## HTML traducible

```html
<button data-i18n="common.play"></button>
<input data-i18n-placeholder="common.search">
<button data-i18n-title="accessibility.languageSelector"></button>
```

Para contenido dinámico usar `TecnoMathI18n.translatePage()` después de insertarlo.

## Juegos

La traducción se separa de la lógica. No se modifican mecánicas, controles, cálculos, respuestas correctas, progreso, rankings, votaciones, autenticación ni Supabase. Las traducciones educativas no se inventan: un idioma sin traducción revisada utiliza el fallback español.

## Validación

Ejecutar `node scripts/validate-i18n.mjs`. El validador comprueba el registro, códigos duplicados, idioma/fallback, JSON y traducciones vacías.

## Integración

La página principal arranca el runtime. El service worker existente se actualiza para inyectarlo en documentos HTML que todavía no lo incluyan y mantiene el comportamiento offline/cache existente. El cambio no requiere migraciones de Supabase.
