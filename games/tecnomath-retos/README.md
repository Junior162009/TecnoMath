# TecnoMath Retos

Minijuego web estático para TecnoMath, sin dependencias ni claves/API.

## Ruta
`games/tecnomath-retos/index.html`

## Funciones
- Conserva los seis retos iniciales: Matemáticas, lógica, Ciencias, Español, Inglés y Sociales.
- Interfaz adaptable a móvil y escritorio, con identidad visual TecnoMath, contraste accesible y animaciones respetuosas de `prefers-reduced-motion`.
- Respuestas con explicación, puntuación, porcentaje de aciertos, racha y récord personal.
- Temporizador opcional de 5, 10 o 15 segundos por pregunta.
- Enlaces opcionales a YouTube, youtu.be y YouTube Shorts; el reproductor no activa audio automáticamente.
- Comparte un reto o resultado con Web Share API y ofrece alternativa para copiar el texto y el enlace.
- Genera una tarjeta de resultado vertical PNG de 1080 × 1920 para compartir o guardar.
- Modo de grabación vertical limpio para capturar la pantalla.
- Sonidos opcionales, desactivados por defecto.
- Guarda respuestas, videos, récord y logros localmente en el navegador; reiniciar conserva videos y récord.
- Metadatos básicos SEO/Open Graph/Twitter y enlace de regreso al portal TecnoMath.
- No necesita dependencias, credenciales, ni cambios de Supabase.

## Uso
Abre la página desde el catálogo, responde las preguntas y, si quieres, pega una URL válida de YouTube o Shorts en la tarjeta correspondiente. El progreso es local a ese navegador y dispositivo. Compartir abre el menú del sistema cuando está disponible; no publica automáticamente en redes sociales.
